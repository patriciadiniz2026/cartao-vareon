---
description: Levar mudanças aprovadas para a main
---
Mostre em 3 linhas o que será publicado (`git log origin/main..HEAD --oneline`).
Se a Patricia já aprovou nesta conversa, faça `git push -u origin HEAD`. Caso contrário, peça confirmação antes.
Não abra PR a menos que ela peça. Informe o resultado em uma linha.
