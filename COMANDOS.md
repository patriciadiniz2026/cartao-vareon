# Lista de comandos (digite a barra / no celular)

## Do dia a dia
| Comando | Para que serve |
|---|---|
| `/status` | Ver como está o projeto e o que está pendente |
| `/ajustar` + pedido | Fazer uma mudança no cartão e testar em tela de celular |
| `/revisar` | Conferir a última mudança antes de publicar |
| `/publicar` | Colocar no ar o que você aprovou |
| `/anotar` + ideia | Guardar uma ideia para depois, sem executar |
| `/email-reuniao` + para quem | Escrever o e-mail da última reunião; só envia depois do seu "enviar" |

## Skills que também funcionam com a barra
| Comando | Para que serve |
|---|---|
| `/grill-me` | O Claude te entrevista antes de começar, com perguntas numeradas |
| `/systematic-debugging` | Achar a causa de um erro antes de tentar consertar |
| `/requesting-code-review` | Pedir uma revisão do trabalho feito |
| `/verification-before-completion` | Conferir de verdade antes de dizer "pronto" |
| `/skill-creator` | Criar ou melhorar uma skill ou comando |
| `/find-skills` | Procurar skills novas para uma tarefa |
| `/webapp-testing` | Testar uma página no navegador |
| `/mcp-builder` | Criar uma conexão com outra ferramenta |
| `/claude-api` | Ajuda com a API do Claude |
